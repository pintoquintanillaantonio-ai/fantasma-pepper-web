
# Fantasma de Pepper — Ilusión Óptica Holográfica

Proyecto web para un emprendimiento enfocado en ilusiones ópticas holográficas basadas en el principio del **Fantasma de Pepper**, combinando visores piramidales y contenido visual en fondo oscuro para exhibiciones, marcas, educación y regalos personalizados.

## Qué incluye la aplicación web
- **Inicio y Beneficios:** Presentación del concepto de ilusión óptica, navegación por secciones y acceso rápido a las herramientas principales.
- **Catálogo y Pedido:** Listado de productos con formato y precio, tabla comparativa, cálculo de total y envío de resumen por WhatsApp.
- **Proyector en Vivo:** Simulador interactivo de proyección en cuatro direcciones para probar el efecto con una pirámide sobre la pantalla.
- **Asistente IA:** Generador de sugerencias visuales y técnicas según la idea del usuario y el dispositivo elegido.
- **Contacto:** Formulario para registrar consultas o solicitudes de cotización.
- **Panel Admin:** Acceso con contraseña para agregar nuevos productos al catálogo y revisar las solicitudes guardadas.
